E-LINGKOD BAYAN — QUICK START (Civic Reporting V7 + Admin Setup)

1. Open this folder (containing package.json) in VS Code.
2. Start MySQL and configure your PRIVATE .env: DATABASE_URL, BETTER_AUTH_SECRET, BETTER_AUTH_URL.
3. First time only / after installing new code:
   npm install
   npx prisma validate
   npx prisma migrate deploy
   npx prisma generate
4. Optional, one time: follow ADMIN-SETUP.md to bootstrap a staff admin account.
5. Run: npm run dev
6. Open: http://localhost:3000

USUAL DAILY START: Start MySQL then npm run dev. You do NOT reinstall or migrate every time.

ROUTES: /reports/new, /reports, /track, /admin/reports, /login, /register.
Civic Reporting is implemented in source. The other five service modules are landing-page concepts only.

For full details, read README.md and ADMIN-SETUP.md.
IMPORTANT: Never share/upload .env containing database passwords or auth secrets.
