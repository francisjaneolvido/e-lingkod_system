E-LINGKOD BAYAN — SERVICES V5 (REPLACEMENT ONLY)
==================================================

What's changed
--------------
Redesigned ONLY the six approved service modules on the landing page.
1. Civic Reporting: large featured tile with community image, photo/GPS/tracking process badges.
2. Online LGU Services: custom application card, permits/taxes/clearances.
3. Emergency Hotlines & Alerts: distinct warm-colored public-safety card.
4. Municipal Directory & Guide: accessible service tile.
5. Job Matching: accessible service tile.
6. Workforce & Social Census: accessible service tile.

Working UI interactions: keyword search, category filtering, service details dialogs,
clear-search action, empty-result reset, and link to the existing tracking demo.

This is a frontend prototype. No actual submission, dispatch, real-time alerts,
verified phone numbers, jobs database or protected census collection is enabled yet.
The community photograph is illustrative, not an actual LGU event.

INSTALL IN WINDOWS / VS CODE
----------------------------
1. Keep a backup of your existing e-lingkod-bayan folder.
2. Stop npm run dev with Ctrl+C.
3. Extract this ZIP.
4. Copy the src and public folders from this ZIP into your existing
   e-lingkod-bayan folder (the folder containing package.json).
5. Choose Replace files in destination when Windows asks.
   Do NOT delete folders already inside your project.
6. Restart: npm run dev
7. Visit http://localhost:3000 and scroll to Digital Service Desk.
8. Hard-refresh with Ctrl+Shift+R if the browser is showing the old version.
