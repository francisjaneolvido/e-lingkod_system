========================================
Identity: eLB | eLingkod Bayan – Los Baños | Report. Act. Resolve.
Retain public/images/elb-mark.svg, familiar destinations and the six service
modules. Images and synthetic examples never establish government endorsement,
operational capability, verified impact or municipality-wide statistics.

TYPOGRAPHY

Body/forms/data:
locally bundled variable Source Sans 3, weights 200–900; ordinary text 400,
labels 550–600, emphasis 600–700. Keep both upstream licence notices in
public/fonts. Source Sans 3 is unmodified Adobe release 3.052R under OFL 1.1.

Frost only real overlapping surfaces, such as sticky headers and modal backdrops.
No indiscriminate gradients, decorative charts or glass-covered forms.

APPEARANCE AND GLOBAL UTILITIES
One compact44px Appearance button cycles Light -> Dark -> OLED -> Light.
No dropdown, menu or three-option selector. Same rightmost aligned header
utility position; header height72px, gaps8px, safe responsive gutters.
The accessible name/title gives current theme and next action; a polite status
announces changes. Click/Enter/Space/tap preserve focus, scroll and saved input.
Keep the synchronous allowlisted theme bootstrap before first paint, deterministic
hydration and safe storage fallback. Do not make authentication depend on storage.
Headerless loading/error routes retain the fallback control; visible headers own
their control. Notifications and navigation have named panels, Escape dismissal
and focus return. Mobile modal navigation traps focus and makes background inert.

INTERACTION AND MOTION
Use motion.css shared120/180/260ms durations and shared easing. Restrained press
compression and state feedback explain actions; drawers reveal with a short
settling transition. Do not animate fields while typing or translate geographic
regions. Use transform/opacity for reveals and explicit transition properties.
Avoid layout jumps, text distortion, hover-only instructions and animation delays.
Keep44px touch targets, stable hit areas and a visible3px focus ring with3px offset.
Disabled controls retain readable full-opacity ink, muted fill, dashed boundary,
native disabled semantics and no press animation. Busy states announce progress.
Reduced motion removes nonessential movement; text, selection and status remain.
Dialogs have a name, heading focus, contained keyboard navigation, Close/Escape
and exact focus return. Touch, keyboard and mouse must reach the same actions.
Every file chooser has a visible keyboard-operable action and clear limits.
Validation, empty, denied, unavailable, error, retry and success states explain the
next available step. Preserve answers/consent when stepping through forms.

ANALYTICS COMPOSITION AND HONEST DATA
Lead with the applied population/year/source/geography and concise headline
metrics. Overview ABOVE filters; detailed tables, complete categories, methodology
and exports BELOW. Desktop uses two rows of three summary slots; real maps are
third and sixth. Two columns on tablet, one on mobile. Keep bars AND appropriate
donuts simultaneously; compact ranked bars suit long/multiselect distributions.
Donuts require exhaustive mutually exclusive categories and one denominator.
Include unknowns and segment boundaries; never infer a percentage or invent Other.
Different source groups/populations remain separate. No manufactured trends,
municipal population claims, account counts substituted for surveys or decorative
values. Report denominator, units, survey year, source and missing/unknown context.
Explicit Apply commits draft filters; reset applies defaults. Keep last applied
context while loading, abort superseded requests and reject obsolete callbacks.
Retry performs a fresh request. Charts/maps/details/CSV use the same applied,
server-authorized response. Exports disappear during unapplied/loading/error states.
Map/chart selection highlights only; applying a geography filter is a separate,
explicit action. Incompatible context closes details safely.

GLOBAL PAGE COMPOSITION
The shared foundation applies to all page families.
visual-reference.css retains the landing and analytics compositions.
Use shallow labelled navigation groups and inline ActionGroup disclosures for
secondary tools. Keep current location, return paths and essential primary actions
visible. Compact navigation still needs readable labels, not mystery icons.

The landing is a guided service entrance: labelled native task choices update a
steady contextual preview and ONE primary next action. Choosing does not navigate
prematurely. Reserve enough height for the longest supported description, keep
choice weight/padding stable, and preserve selection through theme changes.
Keep report tracking (/track), emergency information and the full service directory
discoverable as contextual secondary paths. Use real photo layering only where
the caption benefits from it; its 96%-card overlay must pass composited contrast.

The analytics workbench leads with applied context and direct geographic recovery.

Back/Forward restores controls/results. Failure does not commit a new URL. Previous
results must be explicitly labelled during loading/failure, with exports withheld.
Permission metadata is separate from applied counts: permitted regions outside
the current view stay navigable WITHOUT their aggregates. Explicit Apply changes
region. Forbidden regions remain inert. Do not broaden exact stored-key authority.

Use two three-slot desktop rows with maps in slots 3 and 6. Ranked top-three bars
