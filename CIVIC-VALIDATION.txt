LIMITS OF VERIFICATION
GPS permissions and location were emulated in the browser. Physical phone GPS,
phone camera capture, and the user's Windows/XAMPP installation were not tested.
OpenStreetMap is an external online preview; map tiles were not available in
the restricted browser test environment. Saved coordinates and written address
were verified independently of the map.
Tests used dummy accounts and an isolated test database. These accounts,
credentials, records, screenshots, database server, and browser tools are not
included in the ZIP. The user's existing database was not accessed.

INSTALLATION
